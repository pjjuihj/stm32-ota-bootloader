# STM32F407VETx Flash 布局

## 芯片信息

- **型号**: STM32F407VETx
- **Flash**: 512KB
- **封装**: LQFP100

## Flash 扇区布局

| 扇区 | 大小 | 起始地址 | 结束地址 | 用途 |
|------|------|----------|----------|------|
| Sector 0 | 16KB | 0x08000000 | 0x08003FFF | Bootloader 代码 |
| Sector 1 | 16KB | 0x08004000 | 0x08007FFF | Bootloader 代码 |
| Sector 2 | 16KB | 0x08008000 | 0x0800BFFF | 控制数据 |
| Sector 3 | 16KB | 0x0800C000 | 0x0800FFFF | Partition A |
| Sector 4 | 64KB | 0x08010000 | 0x0801FFFF | Partition A |
| Sector 5 | 128KB | 0x08020000 | 0x0803FFFF | Partition A |
| Sector 6 | 128KB | 0x08040000 | 0x0805FFFF | Partition B |
| Sector 7 | 128KB | 0x08060000 | 0x0807FFFF | Partition B |

## A/B 分区布局

```
STM32F407VETx Flash (512KB)
┌──────────────────────────────────────────┐
│ Sector 0-1 (32KB)   │ Bootloader 代码    │ 0x08000000
├──────────────────────┼───────────────────┤
│ Sector 2 (16KB)     │ 控制数据          │ 0x08008000
├──────────────────────┼───────────────────┤
│ Sector 3-5 (208KB)  │ Partition A (App) │ 0x0800C000
├──────────────────────┼───────────────────┤
│ Sector 6-7 (256KB)  │ Partition B (App) │ 0x08040000
└──────────────────────┴───────────────────┘
```

## 分区地址表

| 分区 | 起始地址 | 大小 | 结束地址 | 最大 App |
|------|----------|------|----------|----------|
| Bootloader | 0x08000000 | 32KB (0x8000) | 0x08007FFF | - |
| 控制数据 | 0x08008000 | 16KB (0x4000) | 0x0800BFFF | - |
| Partition A | 0x0800C000 | 208KB (0x34000) | 0x0803FFFF | 208KB |
| Partition B | 0x08040000 | 256KB (0x40000) | 0x0807FFFF | 256KB |

## 控制数据结构 (Sector 2)

```
Sector 2 (0x08008000 - 0x0800BFFF):
┌──────────────────────────────────────────┐
│ 0x0800BF80 - 0x0800BFDF │ 错误日志 (128B) │
│ 0x0800BFE0              │ 回滚标志 (4B)   │
│ 0x0800BFE4              │ App CRC (4B)    │
│ 0x0800BFE8              │ 活动分区 (4B)   │
│ 0x0800BFF0              │ Boot 魔数 (4B)  │
└──────────────────────────────────────────┘
```

## 控制数据地址定义

| 地址 | 内容 | 大小 |
|------|------|------|
| 0x0800BFF0 | Boot 魔数 (0x424F4F54) | 4B |
| 0x0800BFE8 | 活动分区地址 | 4B |
| 0x0800BFE4 | App CRC32 | 4B |
| 0x0800BFE0 | 回滚标志 (0x524F4C42) | 4B |
| 0x0800BF80 | 错误日志 (8条 × 16B) | 128B |

## OTA 命令格式

```
ota_start <固件大小>     # 例如: ota_start 4436
ota_data <hex数据>       # 例如: ota_data 01020304...
ota_end <CRC32>          # 例如: ota_end 12345678
```

## 注意事项

1. **Sector 0-1 不能擦除** — Bootloader 代码在此执行
2. **Sector 2 可以擦除** — 控制数据区域
3. **Sector 3-7 可以擦除** — App 区域
4. **Flash 只能 1→0** — 写入前必须擦除
5. **App 大小不能超过 208KB** — Partition A 上限
